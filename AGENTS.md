# AI Agent Instructions

This document provides instructions for AI agents contributing to this project. Following these guidelines will ensure consistency, quality, and adherence to best practices.

## General Principles

- **Follow the Plan:** Adhere to the project plan and complete tasks in the specified order.
- **Verify Your Work:** After every change, use tools like `read_file` or `ls` to verify that the changes were applied correctly.
- **Test Your Code:** Write and run tests to ensure that your changes are working as expected and do not introduce regressions.
- **Be Resourceful:** Use the available tools to explore the codebase, diagnose issues, and find solutions.

## Technical Guidelines

- **Authentication:** Use Clerk for all authentication and user management features.
- **Database:** Use Prisma as the ORM for all database interactions.
- **Styling:** Use `tailwindcss` for styling and Radix UI for components. Follow the existing design system and coding conventions.
- **State Management:** Use React hooks and context for state management. Avoid introducing new state management libraries without prior approval.
- **API Routes:** Use Next.js API routes for all backend functionality.

## Contribution Workflow

1. **Understand the Task:** Before starting, make sure you have a clear understanding of the task and its requirements.
2. **Create a Plan:** Break down the task into smaller, manageable steps.
3. **Implement the Changes:** Write clean, maintainable, and well-documented code.
4. **Test Your Changes:** Add or update tests to cover your changes.
5. **Submit for Review:** Once your changes are complete and tested, submit them for review.

By following these instructions, you will help us build a high-quality and maintainable application.
